# Playtest Notes

A small feedback form for user testing my projects. The first version is set up for my custom physics engine and Roblox playtest. Asking about the overall experience, what players enjoyed, anything confusing or broken, and whether they would play again.

## Run it

Open `index.html` in a browser. No build step is required.(Likely to change to some constant website page)

## Current prototype limitation

The form saves responses to the browser's local storage, will need to update with server storage.

## Tests

Run the Playwright tests with:

```sh
npm test
```
